# FocusMap 专注图谱 v2

这是一个可以直接运行的纯前端项目。

## 运行方式

1. 解压压缩包
2. 双击 `index.html`
3. 用浏览器打开即可

## 这一版修复了什么

- 主程序改成单文件，CSS、JS 和主题 SVG 插画都内嵌在 `index.html` 中
- 即使资源文件路径失效，页面也会显示完整主题和插画
- 页面不再全挤在一起，改成侧边栏切换
- 三套主题都有动态背景
- 专注页面会显示主题插画，并每隔一段时间切换

## 功能

- 周任务
- 每日任务
- 今日任务图谱
- 节点完成后划掉
- 专注计时
- 休息倒计时
- 分心原因记录
- 预计用时和实际用时记录
- 掌握程度记录
- 本地智能学习分析
- 数据保存在浏览器 localStorage

## 主题

- 宇宙航行风
- 中国武侠风
- 原创软萌奶龙风

`assets` 文件夹里额外放了 9 张 SVG 主题图片，方便你后续单独使用或修改。

## 注意

不要在压缩包预览里直接打开。请先解压，再双击 `index.html`。
